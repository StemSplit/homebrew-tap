# StemSplit Homebrew Tap

Official Homebrew tap for [StemSplit](https://stemsplit.io) tools.

## Install

```sh
brew tap StemSplit/tap
brew install stemsplit
```

## Tools

| Formula | Description |
|---|---|
| `stemsplit` | CLI for AI audio stem separation via the StemSplit API |

## Usage

```sh
export STEMSPLIT_API_KEY=sk_live_xxxxxxxxxxxxx
stemsplit separate song.mp3
```

Get your API key at [stemsplit.io](https://stemsplit.io).
